# 对话权限保存与验收

## 2026-09-07：新建对话权限切换后自动回退

### 根因

真实网关的 `thread/settings/update` 返回了
`desktop-thread-owner-request-failed:TypeError: Class constructor … cannot be invoked without 'new'`。

Desktop 模块同时导出 RPC 客户端类和创建客户端的工厂函数，两者源码都包含
`getRemoteMain`。旧桥接逻辑取第一个匹配导出，误把类当函数调用。
请求失败后前端回滚权限，但错误只进入连接错误状态，已连接的对话页不会显示。

### 修复边界

- 工厂发现跳过类导出，仍防护字符串转换会抛错的 callable；提高 helper 版本，使已有窗口更新旧逻辑。
- 设置保存返回 Promise，由输入框统一处理权限、模型和思考强度的失败提示。
- 失败只回滚本次提交的设置字段，不覆盖期间收到的正文、轮次和状态。
- 不改变权限语义，不把保存失败当作成功，也不忽略后台返回值以维持表面选择。
