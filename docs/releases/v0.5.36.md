# Codex Remote v0.5.36

- 修复手机端确认重启 Desktop 后，被电脑上 Codex 自带的退出确认阻塞的问题。重启改为强制结束当前用户、指定应用路径对应的 Desktop 主进程，再带桥接参数重新打开；不再发送普通退出 AppleScript。
- 按完整可执行文件路径匹配进程，支持路径中包含空格，避免按进程名称误杀其他应用。保留手机上的一次确认及并发重启保护，更新提示说明强制结束可能中断工作或丢失未保存内容。
- 修复官方 Gateway 启动脚本覆盖外部 `ALLOWED_ORIGINS` 的问题：将传入的精确来源与本机来源合并。同时默认接受 HTTPS `*.ts.net` 页面来源，支持 Tailscale Funnel 登录和 WebSocket；无口令或错误口令仍返回 401，HTTP 或伪装后缀不会匹配默认规则。
- 本次仅处理重启确认问题，不包含尚未确认根因的手机图片显示修复。包含 ARM64 和 Intel x86_64 Mac 包，以及 Android/iOS 包。

按用户要求，没有在开发者本机运行测试、重启 Codex/Gateway 或安装本版本。回归测试、构建和包校验由发布 CI 执行；真实 Codex 退出弹窗场景留给其他电脑验收。
