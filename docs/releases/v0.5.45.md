# Codex Remote v0.5.45

- 修复新版 Desktop 中运行会话无法排队或转为引导：兼容专用队列服务，交由会话 owner 更新目标队列并唤醒执行，不再调用已移除的全局状态路由。
- 兼容 RPC 工厂迁入 app-shared，以及主进程托管会话的接口；旧版 renderer owner 从独立窗口转发，避免请求发送者恰好是 owner 时自路由超时。
- 停止改走 Desktop 的用户停止流程，同时暂停自动目标、清理执行，避免只中断一轮后继续启动。IPC 拒绝响应不再误报成功。
- 兼容 Desktop CLI 新目录，保留旧目录回退。图片上传协议和上传后发送顺序保持不变，Android 仍使用聊天 WebSocket 上传。

验证：完整检查 77 个测试文件、1112 项通过（包含一个保留在本地、未纳入发布的既有测试）；电脑和手机浏览器的流式控制、断线后投递及图片发送 6 项独立交互回归通过。真实 Desktop 会话验证排队保存、转为引导、单次回复及停止；自动目标停止后回读为 paused。手机尺寸页面验证排队、引导和停止。Mac 本地构建、签名、自检及安装后的管理窗口验证通过，未重启 Codex Desktop。

完整 E2E 串跑未全绿，共享会话 fixture 的运行状态和审批残留影响后续用例；不将独立通过等同于整套通过。Android/iOS 本轮没有真机验收，IPA 仍需自行签名。本次服务端修复必须更新 Mac，不能只更新手机端。
