# Codex Remote v0.5.38

- Markdown 中的 Mermaid 代码块现在渲染为图表。渲染库随应用打包、按需加载；流式输入或语法错误时保留源码，内容更新后重新渲染。普通代码块保持原来的展示方式。
- 工具返回的图片现在直接显示在执行过程折叠区域外，支持原有的鉴权下载和点击预览。此前图片藏在“执行过程 → 查看输入与结果”两层折叠里，生成图片默认不可见。
- 图片加载失败时区分下载请求、HTTP 状态、读取图片数据、创建预览和下载后显示失败，不展示可能包含口令的原始异常。
- Mermaid 使用 strict 模式，以 SVG 图片展示；流程图中的图片和图标节点暂不支持，回退源码，避免渲染时等待外部图片。

桌面和移动尺寸 Chrome 已验证流程图、时序图、错误恢复、普通代码块，以及工具图片默认可见和图片预览。Android 16 模拟器 WebView 中已验证流程图和时序图显示。

**手机上传后一直加载或加载失败的问题仍未确认根因。本版没有修改图片下载协议，也不代表该故障已修复；新增阶段提示用于后续真机定位。** Android 真机和 iOS 原生交互尚未验证。
