## Android 后台监控修复

- 修复旧状态请求阻塞后，点击重试或切换连接仍要等待旧请求的问题。重试会取消旧请求，迟到结果不能覆盖当前连接的状态。
- 后台状态检查增加独立的 15 秒截止时间；慢速响应不会一直卡在检查中，失败后自动轮询恢复。
- 修复已恢复正常后，页面被迟到的旧失败结果重新覆盖的问题。
- 区分鉴权、请求超时、地址解析、安全连接、网关 HTTP 错误和 Desktop 桥接不可用；真实故障仍会提示，不伪报健康。
- 保留原有运行、完成、失败通知及 App 图标，不修改图片发送和接收逻辑。

## 验证与边界

- TypeScript 与 Vitest：1008 项通过；Web E2E：61 项通过，9 项既有平台跳过。
- Java 单测通过；Android 模拟器原生监控／通知测试 5 项通过，覆盖慢响应、自动恢复、手动重试、切换连接、迟到响应、HTTP 401/503/302、无效／超限响应和通知投递。
- 使用模拟器中已保存的本机连接另跑原生联调，连续两轮状态检查正常、错误清空；这不是 Web 网络模拟。Mac 锁屏后的页面手动点击未复验。
