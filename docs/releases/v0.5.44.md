# Codex Remote v0.5.44

- 新消息、排队和转为引导改为服务端异步执行。服务端确认接收后立即释放输入框；切换会话、刷新或关闭客户端连接不会取消后续发送。
- 将新消息的“排队→引导”两步移到服务端，避免客户端在两次请求之间断开而中断引导。按会话顺序处理连续提交，并保留消息标识去重。
- 显示服务端接收、投递失败和结果待确认状态，重连后恢复回执。只允许重试已确认失败的消息，避免回执丢失时重复发送。
- 图片仍先完成上传，再提交消息；Android 原生端继续使用聊天 WebSocket 上传。

启用异步发送需同时更新 Mac 服务端及客户端。旧服务端继续使用原有发送方式。本次后台任务和回执由当前 Gateway 进程维护，尚未增加服务端崩溃或重启后的任务恢复。

验证范围：新增服务端、客户端及状态组件 9 项回归通过，电脑与手机浏览器验证接收后刷新仍可送达。Android 模拟器已安装调试包，验证触摸发送、快速回执、关闭客户端页面并切入后台后继续投递，以及回到应用读取已发送消息。完整检查 77 个测试文件、1106 项测试通过；电脑和手机浏览器的刷新后投递及图片发送 4 项交互回归通过，生产构建和 Android 调试构建通过。iOS 真机尚未验证；IPA 未签名，需自行签名安装。
