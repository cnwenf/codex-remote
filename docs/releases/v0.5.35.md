## Android 图片复用聊天连接

- 修复聊天正常、原生 HTTP 上传无响应时图片等待几十秒失败的问题：Android 图片改走已连通且已认证的聊天 WebSocket。
- 保留图片压缩和 1 MB 传输上限，上传完成后才提交图片消息。切换连接或关闭连接页时，不把尚未发送的图片提交到其他连接或旧任务。
- Android 和 Mac 网关都需要更新至 0.5.35；连接旧网关时立即提示更新 Mac。
- 继续提供 Apple Silicon 和 Intel x86_64 的 Mac 安装包。iOS/Web 图片传输保持原有方式。

本地全量检查 1018 项、Web 回归 62 项、Android Java 单测 21 项通过；Android WebView 三种图片大小的故障注入上传和消息提交通过。

详见[定位及回归记录](https://github.com/cnwenf/codex-remote/blob/main/docs/android-image-timeout-acceptance.md)。手机私网的底层网络原因仍未确认，故障注入和模拟器结果不等同于该手机实测。
