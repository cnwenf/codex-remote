# Codex Remote v0.5.40

v0.5.39 的 Android 构建因 SDK 初始化依赖已下架的 `tools` 包而中止，未发布正式安装包。本版修复发布流水线，保留原标签并顺延版本，包含以下更新：

- 图片发送新增逐图上传圆环和百分比：预览图独立显示上传进度，服务端确认成功才到 100%。上传失败保留图片和文字，支持重试；输入框收起后仍可查看预览与进度。Android 保持聊天 WebSocket 上传，原有压缩规则和先上传、后发送消息的顺序不变。
- 优化原始用户问题定位：本地持久化问题索引，优先使用尾部检查点和增量读取，减少打开长对话时反复向上翻页。历史问题仍按对应轮次定位，不用最新问题替代未知历史问题。
- 工具执行过程改为可展开的聚合状态，展示当前阶段和执行内容，运行中使用浅灰色文字扫光，遵循系统减少动态效果设置。
- 修复 macOS Dock 图标边缘留白与菜单栏图标变方块的问题；菜单栏使用独立透明底模板图标。
- 增强 Desktop 连接恢复：渲染上下文失效时重连；Desktop 启动或升级后持续约 20 秒没有调试端口时，Remote 对该进程自动尝试一次重启恢复。主动退出 Desktop 不会自动拉起，已有调试参数的进程不会进入重启循环。

**注意：自动恢复时重启 Desktop 可能中断刚启动的任务。**

验证范围：本地完整测试通过，桌面及移动尺寸浏览器已验证逐图进度、限速上传和断网重试；macOS 图标已实机确认。本轮 Android 真机与 iOS 真机交互尚未验证，iOS IPA 为未签名包，需自行签名后安装。
