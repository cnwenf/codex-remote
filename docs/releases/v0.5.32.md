## 修复与改进

- 图片发送前统一压缩，单张传输副本不超过 1,000,000 字节；Mac Remote 下载历史大图时也按需生成压缩副本，不修改原图或会话原文。
- 图片预处理增加像素、并发、超时和资源释放限制。压缩失败明确报错，不回退发送超限原图，也不自动重复提交消息。
- 修复同一次用户消息在实时事件、历史恢复和重连后重复显示的问题；保留真正连续发送的同文消息及各自图片。
- 恢复 Android 任务运行、完成通知及监控状态提示，补充权限关闭和连接恢复提示。
- 通知完整图标复用 App 的图形、留白和黑色背景；状态栏小图标使用同源单色轮廓，遵循 Android 系统模板。
- 禁止原生桥日志记录凭据和图片请求内容。

## 升级说明

- 建议同时升级 Mac Remote 和 Android 客户端，完整启用双向图片压缩。
- Android APK 沿用固定正式签名，可覆盖同签名旧版本。系统的未知来源或 Play Protect 提示不代表 APK 未签名；本版本不会关闭系统安全检查。
- 大图使用静态 JPEG 传输副本，透明区域铺白底，大 GIF 不保留动画；已保存的原图不变。

## 验证范围

- 发布前完整自动化检查包含 1001 项；Web E2E 61 项通过、9 项为既有平台跳过，Java 单测 21 项、Android 原生测试 5 项通过。最终标签流水线另行重跑检查与全部平台构建。
- 候选已安装至 Mac、Android 和 iPhone 模拟器。真实 9.24 MB 图片经 Android、iPhone、Web 发送后分别约 915 KB、963 KB、913 KB；新 Gateway 历史下载约 828 KB，原图校验和不变。
- 实际核验连续同文、双向图片和最终回复、跨端排队转引导、Android 完成通知跳转；受控 Gateway 中断后 Web 自动恢复且消息不重复。

## 已知限制与未验收项

- iPhone 完整历史上翻手势，以及最后一次 Gateway 中断后的两端原生页面复验尚未完成；VPN、蜂窝网络和手机厂商后台策略仍需真机补测。
- 新回复刚落盘时，原问题置顶可能短暂提示未找到，随后自动恢复；本版本不声称已消除此提示。
- 图片传输压缩不改写 Codex 已有大图片会话的模型请求，不能保证消除旧会话的上游 HTTP 400。
- Android 系统决定通知分组、折叠与锁屏展示方式，不承诺所有模板都展示完整大图标。
- iOS 提供模拟器包和未签名 IPA；实体 iPhone 安装仍需要有效的 Apple 开发者签名。
