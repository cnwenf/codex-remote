# Codex Remote v0.5.47

- 修复发送超时后旧 CDP 连接未释放、桥重连反复失败导致 Remote 只读的问题；只重连桥，不重启 Codex Desktop，停止重连时清理迟到连接。
- 修复新版 Desktop 未登记 owner 的运行会话停止、排队及引导失败。先检查实际归属；无 owner 时补最新一轮缓存并使用原生控制接口，不恢复或接管任务，不改变模型和权限配置。
- 无 owner 的队列只修改目标消息，保留其他会话及同一会话并发排入的消息。投递超时或断连不换路径重复发送；目标暂停失败和停止未确认不再误报成功。
- 包含 0.5.46 的 Update Plan 恢复修复。图片发送协议及上传顺序保持不变。

验证：专用真实会话排队持久化、引导和停止通过，最新轮次为 interrupted；正式桥保持 desktop-live、可写，Desktop 进程未重启。隔离回归覆盖 owner/follower/无 owner 路由、自动目标暂停错误、停止未确认、桥重连和取消竞态。Android/iOS 真机未验收。

完整检查 77 个测试文件、1121 项通过（包含一个保留在本地、未纳入发布的既有测试）。构建通过；电脑及手机尺寸的控制、审批、计划、差异、图片发送与刷新后继续发送 6 项专项 E2E 通过，不等同于完整 E2E。

修复位于 Mac Gateway，必须更新 Mac 端，不能只更新手机端。IPA 仍需自行签名。
