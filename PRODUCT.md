# Product

## Register

product

## Users

The primary user is the owner of the Mac running Codex Desktop. They use a phone browser over an existing private VPN to check long-running coding tasks, send follow-up instructions, stop work, inspect changes, and answer approval requests without opening a full remote desktop session.

## Product Purpose

Codex Remote provides a fast, focused mobile control surface for local Codex work. Success means the user can move from opening the page to understanding task state or taking the next action in seconds, while the current Desktop process remains untouched during phase one.

## Brand Personality

Focused, calm, trustworthy. The interface should feel familiar to a Codex Desktop user, with direct language and visible system state rather than decoration.

## Anti-references

- Full remote-desktop interfaces with tiny desktop controls and high bandwidth use.
- Generic SaaS dashboards built from repetitive cards and decorative metrics.
- Terminal replicas that make routine task control harder on a phone.
- Hidden or automatic approval behavior.

## Design Principles

1. Put the next useful action within thumb reach.
2. Make connection, execution, stale data, and approval state explicit.
3. Preserve familiar Codex concepts without copying bundled implementation assets.
4. Prefer compact progressive disclosure over dense desktop controls.
5. Treat safe denial and recovery as first-class flows.

## Accessibility & Inclusion

Meet WCAG 2.1 AA contrast and keyboard expectations, maintain visible focus, use at least 44 CSS pixel touch targets, honor reduced motion and system color scheme, support safe-area insets, and never rely on color alone for status.
